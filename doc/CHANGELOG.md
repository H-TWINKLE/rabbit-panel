## v2.1.2 (2026-04-7)

## v2.1.1 (2026-01-19)

**AI 运维助手工具集大幅扩展**
- **工具从 7 个增至 26 个**，覆盖系统全部容器相关操作：
  - **容器管理 (8)**: 列出/启动/停止/重启/删除容器、查看日志、检查详情、**创建并运行新容器**
  - **镜像管理 (3)**: 列出/拉取/删除镜像
  - **网络管理 (4)**: 列出/创建/删除/检查网络
  - **存储卷管理 (3)**: 列出/创建/删除存储卷
  - **Docker Compose (5)**: 列出项目/启动/停止/重启/查看状态
  - **系统维护 (3)**: 系统状态/清理容器/清理镜像
- **新增 `run_container(image, name)`**: 支持从镜像直接创建并启动容器
- **修复 `pull_image`**: 正确等待镜像拉取完成，避免超时误报
- **输出优化**: 所有工具输出均已格式化为 Markdown 表格

## v2.1.0 (2026-01-18)

**新功能：AI 运维助手 (Agent)**
- **自然语言交互**：集成 LLM 大模型，通过聊天窗口管理服务器与容器
- **智能多步执行**：支持复杂任务链（最多 3 步）
- **协议升级**：采用 `[[TOOL: function(args)]]` 协议
- **可视化运维**：实时展示执行日志，Markdown 格式呈现
- **历史记录持久化**：SQLite 存储聊天历史，自动清理过期数据

**体验与 UI 优化**
- 优化聊天浮窗动画，消除闪烁
- 输入框自动对焦及发送后智能重聚焦
- 重构 SSE 解析逻辑，解决多行乱码问题
- 优化系统 Prompt，减少跑题
